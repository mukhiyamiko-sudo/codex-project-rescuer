# Codex 项目恢复工具

用于恢复 Codex 左侧“项目”区域中消失的本地项目。

## 使用方法

1. 可以先打开工具并点击“扫描项目”。
2. 恢复前，从系统托盘完全退出 Codex；确认任务管理器中没有 `ChatGPT.exe` 或 `codex.exe`。
3. 勾选需要恢复的项目，点击“恢复勾选项目”。
4. 成功后重新启动 Codex。

当前 Codex 中已有的项目拥有最高优先级。同名或同路径的历史项目会自动跳过，不会覆盖或重复添加。

## 备份与回滚

恢复前会自动备份状态文件，成功后只保留最近一次完整备份。需要撤销时，退出 Codex 后点击“一键回滚”。

备份目录：`%USERPROFILE%\.codex\project-restorer-backups`

工具不会删除、移动或修改任何项目文件夹，也不会联网。
